## 5. Calibrated tail estimate

Method (`c3sim/calibration.py`): cross-fit. Split A_train accounts 90/10 (seed 104); fit histogram head + 3-gram on the 90%; in each log10(p^) bin the factor r = held-out tail mass / model tail mass (the model mass by sampling 20M strings from the 3-gram, head strings excluded exactly); apply r to the tail p^ of the estimator trained on all of A_train. Head (top 100,000) unchanged. It is a public function of the string. A_dev is used only as the design target pool; A_fresh was touched once (5.3). The est attacker uses the deployed (calibrated) p^ for the fix and plain p^ for the base.
